# Checkmate

A Chrome extension for Canvas LMS: shows only the work that's actually due, with a modern look and a pile of optional extras. Forked from the MIT-licensed [BetterCanvas / ActuallyBetterCanvas](https://github.com/GuySandler/ActuallyBetterCanvas).

## Highlights
- Progress rings and a "N left" counter for the next 7 days (plus recent unfinished work)
- Redesigned sidebar, week strip, Tasks panel, and a five-pane settings popup
- Grade analytics with a target calculator and "can still improve" list
- "Coming up" card for exams and next class, `.ics` export, due-soon alerts
- Focus timer, notes and steps on assignments, day/night theme slots
- Dark mode with a repair pass for light surfaces

## Install (unpacked)
1. Download or clone this repo.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and pick this folder.
4. After pulling changes, hit the reload icon on the extension card.
